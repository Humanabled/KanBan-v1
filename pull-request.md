# Pasos para hacer una Pull Request en GitHub

## ¿Qué es una Pull Request?

Una Pull Request (PR) es una herramienta de GitHub que permite proponer cambios en un proyecto para que otros compañeros puedan revisarlos antes de incorporarlos a la rama principal.

## Pasos para crear una Pull Request

### 1. Crear una rama (Branch)
Entrar en el repositorio y crear una rama nueva desde la rama principal. Cada persona trabaja en su propia rama.

### 2. Realizar los cambios
Crear o modificar los archivos necesarios para realizar la tarea asignada.

### 3. Guardar los cambios (Commit)
Guardar los cambios mediante un commit, escribiendo un mensaje que explique qué se ha modificado.

### 4. Subir los cambios (Push)
Subir la rama y sus cambios al repositorio de GitHub.

### 5. Crear la Pull Request
Entrar en la pestaña Pull Requests y pulsar en New Pull Request. Seleccionar la rama principal como destino (base) y nuestra rama como origen (compare).

### 6. Añadir información
Escribir un título y una descripción explicando los cambios realizados. Añadir `Closes #número` para relacionar la Pull Request con su Issue correspondiente.

### 7. Revisar la Pull Request
Otro compañero debe revisar los cambios en Files changed, dejar al menos un comentario y aprobar la Pull Request.

### 8. Hacer Merge
Una vez aprobada, se puede hacer Merge para incorporar los cambios a la rama principal.

## Conclusión

Las Pull Requests permiten trabajar en equipo de forma organizada, revisar los cambios antes de incorporarlos y evitar errores en el proyecto.
